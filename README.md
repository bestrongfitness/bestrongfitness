# Be Strong Fitness

A professional, responsive marketing site for Be Strong Fitness, built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Scripts

- `npm run dev` — start the development server.
- `npm test -- --run` — run the test suite once.
- `npm run build` — type-check and build the production app.

## Initial stack

React, TypeScript, Vite, Tailwind CSS, React Router, Motion, Lucide React, Embla Carousel, and Sonner. Data fetching, global state, forms, and validation libraries will be added only when the site gains API-backed or interactive features.

## Content updates

Business copy, facilities, testimonials, and contact details live in the typed content module under `src/data/` once the homepage sections are added. Sample reviews remain clearly marked until approved member review text is supplied.
